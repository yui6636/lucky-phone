# 🍀 Lucky机 · 千禧年翻盖AI聊天机

一个运行在浏览器里的千禧年翻盖手机模拟器，内置四叶草主题AI聊天。

## ✨ 功能

- 📱 翻盖手机外观 + 开场动画
- 🍀 四叶草主题，千禧年QQ风格
- 🤖 接入任意 OpenAI 兼容接口
- 👥 多角色管理，每个角色独立记忆
- 📖 每个角色独立世界书（世界观）
- 🍀 朋友圈：AI达到轮数自动发动态
- 💰 转账功能
- 🧠 长期记忆（AI自动总结对话）
- 🌐 双语模式（外语自动翻译）
- 🏠 线上线下模式（线下可动作描写）
- 💬 分句模式（AI一次可发多条）
- ⌨️ T9键盘（数字/拼音/英文）

## 🚀 如何部署

### 方法一：直接下载（最简单）

1. 点右上角绿色的 **Code** 按钮 → **Download ZIP**
2. 解压后双击 `index.html`
3. 用浏览器打开，就能用了

### 方法二：部署到自己的网站

把 `index.html` 上传到任何静态托管服务：

- **GitHub Pages**（免费）
- **Vercel**（免费）：vercel.com
- **Netlify**（免费）：netlify.com
- **Cloudflare Pages**（免费）：pages.cloudflare.com
- 或者你自己的服务器

上传后，访问对应的网址就能用。

### 方法三：Fork 我的仓库

1. 点右上角的 **Fork** 按钮
2. 复制到你的账号下
3. 修改成你想要的样子
4. 部署

## ⚙️ 如何配置AI

1. 打开网页，点击右上角「⚙️ API」
2. 填入：
   - **API地址**：如 `https://api.openai.com/v1`
   - **API Key**：你的密钥
3. 点击「🔄 自动拉取模型列表」，选一个模型
4. 保存，开始使用

> 支持所有 OpenAI 兼容接口（OpenAI、DeepSeek、通义千问、Kimi、Claude代理等）

## 📝 自定义

- **改角色**：点「🍀 角色」→ 创建角色
- **改世界观**：点「📖 世界书」→ 编辑
- **改默认设置**：直接编辑 `index.html` 里的 CSS 和 JS
